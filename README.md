# Dev Full Stack

Backend application developed with Java and Spring Boot as part of a full-stack project.

The project works alongside the [Helpdesk Frontend](https://github.com/MaiaMDC/helpdesk-front), providing the backend layer of the application.

## Technologies

- Java
- Spring Boot
- Maven

## Getting Started

### Prerequisites

- Java JDK
- Git

### Running the Application

1. Clone the repository:

   ```bash
   git clone https://github.com/MaiaMDC/Dev-Full-Stack.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Dev-Full-Stack
   ```

3. Run the application:

   **Linux / macOS**
   ```bash
   ./mvnw spring-boot:run
   ```

   **Windows**
   ```bash
   mvnw.cmd spring-boot:run
   ```
